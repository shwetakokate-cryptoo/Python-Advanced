# Python Advanced

A collection of advanced Python concepts with practical examples and clean implementations.

## Topics Covered

### 1. Decorators

Decorators allow you to modify or extend the behavior of functions without changing their original implementation.

#### Features

- Function Wrapping
- Code Reusability
- Separation of Concerns
- Clean Function Enhancement

#### Concepts Covered

- Decorators
- Higher-Order Functions
- Nested Functions
- Function Wrapping

## 2. Generators

Generators produce values one at a time using the `yield` keyword instead of storing the complete sequence in memory.

### Features

- Lazy Evaluation
- Memory Efficiency
- Sequential Data Processing
- Generator Pipelines

### Concepts Covered

- Generators
- `yield`
- Lazy Evaluation
- Iteration
- Memory Optimization
